# 界面设计约定

首页用于快速看数据，设置和全部记录分别使用独立 Activity。

- 首页顺序：最新体重及较上次变化 → 双曲线趋势 → 最近 3 条 → 设备连接状态。
- 首页边距 16 dp，卡片间距 12 dp，卡片内边距 12–16 dp，圆角 18 dp。
- 主数值 54 sp，自适应缩小以容纳窄屏和大字号；正文 14 sp，辅助文字 12–13 sp。
- 控件保留至少 48 dp 点击区域，压缩视觉留白时不缩小触摸范围。
- 用中性灰白/深灰背景承载内容，青绿色用于上午和主要操作，金色用于下午。
- 系统栏颜色与页面协调，内容避让系统栏、屏幕缺口和软键盘。
- 全部记录按日期分组，同一天共用一张卡片，组内用细线分隔。
- 设置使用明确的保存入口。直接返回不写入设置，旋转屏幕保留草稿。
- 图表保留点击/滑动查值与历史浏览；历史浏览入口显式切换两种交互。
- 恢复记录的技术说明放在详情中，首页只显示保存状态。

实现保留 Java Views + Material 架构，使用共享的 `Ui` 组件统一三页。
不迁移数据库，也不因浏览页面或切换筛选重新发送 Webhook。
