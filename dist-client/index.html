三步完成部署 Windows 调试助手：

  1. 下载并解压 remote-bridge-windows.zip 到你喜欢的目录（如 D:\tools\remote-bridge）。
  2. （可选）右键使用 PowerShell 运行 Create-Desktop-Shortcut.ps1，自动生成桌面图标。
  3. 双击 Start-Bridge-Tray.bat 运行即可。连接成功后右下角托盘会提示连接正常。

或者直接在 Windows PowerShell 终端中一行命令自动下载并启动：

iwr -useb "CURRENT_PAGE_URL/remote-bridge-windows.zip" -OutFile "$env:TEMP\bridge.zip"; Expand-Archive "$env:TEMP\bridge.zip" -DestinationPath "$env:USERPROFILE\Desktop\RemoteBridge" -Force; Start-Process "$env:USERPROFILE\Desktop\RemoteBridge\client\Start-Bridge-Tray.bat"
